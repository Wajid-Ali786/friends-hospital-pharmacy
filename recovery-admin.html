Recovery Code Helper

Verify the user's identity first. Generate a short code, then copy its hash into the matching Firebase recovery request.

1. Recovery code — send this to the user
------
2. SHA-256 hash — paste this into Firestore
Generate a code first

Firebase document: editModeRecoveryApprovals/{USER_UID}
Fields: approved = Boolean true; codeHash = copied hash; expiresAt = Firestore Timestamp, 24 hours ahead.
Use the UID of the matching request. Each request needs its own new code and hash. The raw code is never stored in Firestore.

This helper works locally in your browser. It does not connect to Firebase or send messages.
