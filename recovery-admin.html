QR code will appear here

Firebase mein approval add karne ka complete method

  1. Firebase Console open karein → Firestore Database → Data.
  2. editModeRecoveryRequests collection open karein.
  3. Jis user ki request approve karni hai, uska document open karein. Document ID/UID copy karein. Email field se user verify karein.
  4. Firestore Data mein wapas jaakar Start collection select karein. Collection ID exactly editModeRecoveryApprovals likhein.
  5. Document ID mein usi request ka UID paste karein. Agar collection pehle se hai, usay open karke Add document karein.
  6. Ye fields add karein, spelling aur types bilkul same rakhein:
approved — Boolean — true
codeHash — String — upar wala copied hash / QR se copied text
expiresAt — Timestamp — current time se 24 hours baad
  1. Save karein. Raw 8-digit recovery code WhatsApp par verified user ko bhej dein.
  2. User app mein Forgot Edit Mode Password khol kar code aur new password enter karega. Successful reset par approval document app khud delete kar degi.
Important: Har request ke liye naya code aur hash banayein. Hamesha usi request ke UID document mein save karein. Raw code ko Firebase mein save na karein. Expiry 24 hours rakhein. Ye helper Firebase se automatically connect nahi hota; aap fields manually add karte hain.

QR contains the salted PBKDF2 hash only. Keep the raw recovery code private and send it only to the verified account owner.
